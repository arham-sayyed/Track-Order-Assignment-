# Icons

Download from [Flaticon](https://www.flaticon.com/) (per the assignment) and drop the
PNG/SVG files here. Expected set:

| file            | usage                          |
| --------------- | ------------------------------ |
| `back.png`      | Toolbar back chevron           |
| `veg.png`       | Veg marker (or draw with View) |
| `nonveg.png`    | Non-veg marker                 |
| `filter.png`    | Filter bar affordance          |
| `cart.png`      | Cart FAB                       |
| `plus.png`      | Quantity stepper `+`           |
| `minus.png`     | Quantity stepper `–`           |

Keep attribution as required by the Flaticon licence.
